What ships in lib/
==================

AshLoader.dll — reference only
------------------------------
Loader commit : 3801a87
Loader version: 1.0.26 (the loader's own version string; it was not bumped for this build)
Hub release   : 1.0.30 (Windows and Linux)
Game build    : 25465256 (Ascent of Ashes 0.2.0-RC4, the public release)
Bytes         : 249856
sha256        : 68b813cae694842d9d9ee3a5b8366464f8a44b6d9cec2a068feaaaf328a8adea

This is the exact file the AshForge Hub deploys next to the game, not a rebuild of it. AshLoader.xml
beside it is the API documentation; your IDE reads it automatically.

With SDK 2.0 your mod's own code never references this assembly. Only the small adapter the build
generates for you (<YourMod>.Loader.dll) does, and it reaches the loader at runtime, so a player
without the AshForge Hub runs your mod exactly the same, and a player with an older or newer loader
gets everything that loader has. You compile against it; you never ship it.

native/0Harmony.dll — shipped in your mod
-----------------------------------------
Harmony 2.3.3, MIT License, Copyright (c) 2017 Andreas Pardeike — https://github.com/pardeike/Harmony
sha256 4b5f44764316c833… (identical in every AshForge mod)

The game does not ship Harmony, so the build copies this file into your mod's Assembly/ folder. Every
mod carrying a byte-identical copy is fine: the first one loaded is the one every mod binds to. Do
not swap it for another Harmony build; two different assemblies named 0Harmony in one process break
the patches of every mod that uses either.

The game's own mod system, and the AshForge Hub
-----------------------------------------------
Ascent of Ashes has its own mod system: a folder in the game's Mods folder with an About.xml, enabled
in the in-game Mods menu. A mod built with this SDK is such a folder, and it is also a complete
AshForge mod. The AshForge Hub adds what the game's system does not have — signature checking,
updates, and the world-state broker for mods to share data — but nothing a player needs to run your
mod. Your settings appear in the AshForge Tools mod's settings screen either way.

There is one lane. The earlier stable and beta lanes ended when the game's beta became its public
release (build 25465256); every player is on this build.
